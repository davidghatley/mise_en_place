02

The problem

Every new task starts with the same scramble: research, hunting for references, making placeholder assets, writing down context. It gets done in a hurry by you or your agent, and half of it gets lost.

04

How it works

  1. Describe the task.

    Say it in your own words. Point mep at your repo or notes if there are any.

  2. Run the prep skills.

    They research, generate assets and gather context with the tools on your machine. Works with Claude Code and bonfire; in development.

  3. Open the prep folder.

    Read the index, then hand the folder to whoever does the work: you, Claude Code, bonfire or another agent.

05

See it work

Plate 5 · A landing pageTarget demo. Not built yet.

You give your agent a task and the prep skills:

> prep this task: "launch a landing page for a small open-source library"

When it finishes, the prep folder holds a keyword study and a competitor table, three hero image drafts made locally, references pulled from your own inspiration library, and a context.md that says what the repo does, written from reading it. index.md lists every item with its source, plus the open questions.

A second, unlike task uses the same steps. Give it “analyse a year of my bank exports” and you get research on categorisation approaches, sample data, context about the file formats and an index.md. Then you or your agent start on the work.

07

Who it's for

For you if

  • You start lots of different projects with AI agents.
  • You want the prep done well and visible, not buried in a chat.
  • You want to read what your agent starts from before it starts.

Not for you if

  • You want a template or starter kit. It ships nothing premade.
  • You want a tool that does the work itself. mep only does the prep.
  • You want something finished today.
08

How it differs

Other tools cover one slice of the prep. Mise en Place is meant to do the whole bundle, for any task.

Plate 8.1

Single-purpose skills

Claude Code skills for project kickoff or competitor research each do one job, mostly for software projects. They don't make assets or gather your references.

Plate 8.2

Context-pack tools

Command-line tools that write down context for an agent. That is one part of the prep: no research, no generated assets, no references.

Plate 8.3

Mise en Place

Research, generated assets, your references and an organized folder with an index, for any task, code or not.

The gapIn our search on 2026-10-19 we found no tool that does all four.

How it fits

Mise en Place is the prep step in a set of five tools David Hatley is building for making things with AI agents.

  • Mise en Placedoes the prep: research, assets, references and context for a task.
  • nibbleanswers an agent's multiple-choice questions fast and says how sure it is.
  • bonfireruns AI agents until the work passes your checks, even through a crash. Mise en Place is built to work with it, so parallel workers can start from the same prep folder.
  • playdoughturns one sentence into a small game you can play from a link.
  • napkin(first build) is a design canvas where you and an AI agent edit the same React components, live.
10

FAQ

Is this a template or starter kit?

No. Not a template or starter kit: everything is made fresh for your task. It ships no premade assets, templates or code.

Is this a coding agent?

No. It is a set of prep skills. The work is yours or your agents'. It preps coding tasks and tasks that aren't code.

What can it prep?

Research, generated assets (images, diagrams, sample data, first drafts), references from your own libraries, and context from your project, in a prep folder with an index. Prep skills are added one at a time.

What does it work with?

Claude Code and bonfire. The skills are in development and just starting.

How is it different from other tools?

Single-purpose Claude Code skills and context-pack tools each do one slice. Mise en Place aims to do the whole bundle for any task: research, generated assets, your references and an organized folder.

Is this the mise tool?

No. That's jdx/mise, a separate tool. We use mep as the short name to keep them apart.

Can I try it today?

No. Nothing has shipped. Read the plan, and watch it get built.
